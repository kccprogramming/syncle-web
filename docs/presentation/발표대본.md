## 예상 질문과 답

1. **기존 투표 도구나 중간지점 서비스와 무엇이 다른가요?** — 따로 입력하지 않아도 대화에서 조건을 모으고, 시간 · 장소 · 목적을 한 회의 안에서 확정까지 잇습니다. 장소는 가운데 좌표가 아니라 사람별 실제 대중교통 시간으로 고릅니다.
2. **AI가 조건을 잘못 이해하면요?** — 시간은 코드가 다듬고 검사합니다. 팀원은 '내 조건'에서 AI가 이해한 내용을 보고, 후보가 안 맞으면 '다른 시간 알려주기'로 고칩니다. 확정은 항상 방장이 합니다.
3. **왜 '차이가 작은 순'인가요? 1시간은 근거가 있나요?** — 한 명만 가까운 곳보다 모두 조금씩 비슷한 곳이 공평하다고 팀에서 합의했습니다. 1시간은 지나친 이동을 먼저 거르는 기본값으로, 팀마다 바꿀 수 있게 할 계획입니다.
4. **출발지를 안 넣은 사람이 있으면요?** — 그 사람은 빼고 아는 사람끼리 계산하고, '미확인 N명 빼고 계산'이라고 화면에 밝힙니다.
5. **이미 카톡이 있는데 왜 새 앱인가요?** — 일과 일상이 섞이지 않는 팀 협업 공간이기 때문입니다. 회의 · 자료 · 할 일이 팀 메뉴에 모이고, AI가 사적인 대화를 읽지 않아도 됩니다. 초대 링크로 설치 없이 들어옵니다.
6. **개인정보는요?** — 정확한 출발지는 서버만 읽고 팀원에게는 동네까지만 보입니다. 파일은 비공개 보관함, API 키는 서버에만 둡니다.

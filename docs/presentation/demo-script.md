# 시연 영상 녹화 대본 (실제 계정 2개)

발표 12장에 넣을 영상이에요. 실제 로그인 · 실제 데이터 · Gemini로 찍어요.
목표 길이 **30~40초** (기다리는 부분은 편집에서 빨리 감기).

- **A 계정** = 희원 (방장, 녹화하는 화면)
- **B 계정** = 다른 Google 계정 1개 (팀원). 초대 링크로 들어와서 출발지만 정하면 돼요
- 주소: `https://syncle-web-git-integration-b-d-unione1.vercel.app`

---

## 0. 미리 준비 (녹화 전)

1. **브라우저 두 개**를 써요. A는 평소 Chrome, B는 Chrome 시크릿 창(또는 다른 브라우저). 같은 창에서 계정을 바꾸면 A가 로그아웃돼요.
2. A 창 높이를 **900px 이상**으로 크게. 그래야 앱 화면이 휴대폰 크기(390×844)로 꽉 차서 발표 장표의 영상 자리와 비율이 맞아요.
3. 녹화는 macOS `⌘ + ⇧ + 5` → '선택 부분 기록' → 앱 휴대폰 화면만 네모로 골라요.
4. **날짜 정하기**: 제안 만들기의 기본 '시간 찾을 기간'은 **모레부터 7일**이에요. 아래 대화의 `날짜1` · `날짜2`를 그 안의 평일 두 날로 바꿔 써요.
   - 예) 11/7(토)에 녹화 → 기간 11/9(월)~11/15(일) → 날짜1 = **11/10(화)**, 날짜2 = **11/11(수)**
5. **출발지 두 곳**: 서로 너무 멀지 않게 (누군가 1시간이 넘으면 그 장소는 빠져요). 예) A 신촌역 · B 건대입구역.
   검색해서 고를 때 '위치 확인 중…' 뒤에 막히면 다른 결과(번지 있는 주소)를 골라요.

### 녹화 전에 해 두면 좋은 것 (영상에서 빼도 되는 부분)

- B 계정으로 한 번 로그인해서 이름 · 출발지를 정해 두면, 영상에서 B 쪽 화면은 안 보여도 돼요. 단, **팀 참여는 A가 팀을 만든 뒤**에만 할 수 있어요 → 아래 2번에서 해요.

---

## 1. 로그인 · 팀 만들기 (A, 영상 약 6초)

1. A 창에서 주소 열기 → **Google로 계속하기** → 희원 계정 고르기
2. 처음 홈(팀 없음) → **새 팀 만들기**
3. 팀명: `중간발표 준비팀` · 주로 출발하는 곳: `신촌역` 검색 → 고르기
4. **팀 만들고 초대 링크 복사** → 대화방으로 들어가요

> 희원 계정에 이미 팀이 있으면 홈에 팀 목록이 나와요. '처음 로그인' 모습을 찍고 싶으면 홈에서 바로 '새 팀 만들기'부터 찍어도 충분해요.

## 2. 팀원 참여 (B, 영상에서는 빼도 됨)

1. 복사한 초대 링크를 B 창(시크릿)에 붙여 넣기 → **로그인하고 참여하기** → B 계정
2. 이름 · 출발지(`건대입구역`) 정하고 **팀 참여하기**
3. A 대화방에 B가 들어온 게 보이면 준비 끝

## 3. 평소처럼 대화 (A · B, 영상 약 6초)

아래 순서대로 보내요. `날짜1` · `날짜2`는 0-4에서 정한 날짜로 바꿔요. **날짜와 시간을 구체적으로** 쓰는 게 AI가 가장 정확하게 읽어요.

| 누가 | 보낼 말 |
|---|---|
| A | 중간발표 자료 역할 나누는 회의 한번 해요! 노트북 챙겨서 같이 작업해요 |
| B | 좋아요. 저는 `날짜1` 19:00~22:00, `날짜2` 18:00~21:00 돼요 |
| A | 저도 `날짜1` 저녁 7시 이후 괜찮아요. `날짜2`는 20시까지만 돼요 |
| B | 주말은 둘 다 안 되는 걸로 해요 |

> 미리 보내 두고 영상은 대화가 쌓인 화면부터 찍어도 돼요 ('예시 대화가 있는 채팅방').

## 4. '@AI 회의 잡아줘' (A, 영상 약 8초 · 기다림은 빨리 감기)

1. 입력창에 `@AI 회의 잡아줘` → 보내기
2. 제안 만들기 시트: 목적(자동으로 채워짐) · 길이 **1시간** · **대면** 확인 → 만들기
3. 몇 초 뒤 대화방에 **제안 카드**가 올라와요 → **되는 시간 고르기**

> "AI 사용량이 잠시 많아요"가 나오면 1분 뒤 다시. "AI가 대화에서 되는 시간을 정확히 읽지 못했어요"가 나오면 3번 대화의 날짜 · 시간이 기간 안인지 확인해요.

## 5. 응답 · 장소 찾기 · 확정 (A · B, 영상 약 12초)

1. (B 창) 대화방 제안 카드 → 되는 시간 누르기 (영상에서 빼도 됨)
2. (A 창) 시간 카드 누르기 → '나 돼요' 체크
3. 장소 칸 **이 시간의 장소 찾기** → 지역 3곳 · 1위 장소 · 사람별 이동시간이 나와요
4. 1위 장소 고르기 → 아래 **○/○ ○○:00로 확정** (모두 응답했으면 바로 확정)

## 6. 회의 카드 (A, 영상 약 5초)

1. **회의 카드 보기** → 시간 · 장소 · 안건 · 내 이동 · 캘린더 · 길찾기
2. 잠깐 멈췄다가 끝. (원하면 '대화방으로' 눌러 확정 카드 한 번 보여주기)
